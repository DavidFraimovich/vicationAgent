# ארכיטקטורה

השורש מנהל Git, כניסות skills והפעלה. agent מרכז קוד, מדיניות, כלים ותהליכים. trips מכיל פרויקטי טיולים; knowledge מכיל העדפות ולקחים עם מקור.

TripContext בוחר לפי tripId את תיקיית הטיול, אזור הזמן, מסד הנתונים, הייצואים והגיבויים. חיבור SQLite נשמר במפה לפי נתיב מסד; אין משתנה טיול נוכחי משותף לבקשות.
list-trips קורא manifests, ולא נשען על מסד גלובלי. רשומות מקום, מסלול, לינה ואודיט נשמרות במסד הטיול שנבחר, גם כאשר מזהים זהים מופיעים בשני טיולים.

CLI תומך --trip; MCP מקבל tripId; הדשבורד בוחר trip ומעביר אותו לכל פעולה. הגדרות ספקים וחשבון משותפות, בעוד timezone, הגנות טיסות ויעד Drive שייכים לטיול.
כללי יומן: ../policies/calendar-policy.md. export-plan-html מאמת JSON, Markdown ו־SQLite; --local-only אינו פונה ל־Drive.

draft מאפשר שלד עם ימים לא מתוכננים ואזהרות. טיול שהושלם שומר תוכנית ותחקיר בנפרד; אין זריעה או סנכרון אוטומטיים של ארכיון.
