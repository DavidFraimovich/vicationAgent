# כלים

- travel_local: הקשר טיול, מקומות, מסלול, לינה ואודיט; כל פעולה בוחרת tripId.
- travel_create_trip / npm run trip:new: פרויקט מקומי עצמאי ללא פרסום חיצוני.
- Google Maps MCP: זהויות מקומות ומסלולים; לקרוא ../policies/maps-policy.md.
- Calendar: לקרוא ../policies/calendar-policy.md לפני כל פקודה.
- Instagram: ../tools/instagram; קוד משותף, תוצאות איסוף שייכות לפרויקט הטיול בלבד. יש לספק INSTAGRAM_SAVE_DIR בתיקיית הטיול.
- Telegram: preview לפני שליחה, יעד מוגדר בלבד, לפי ../policies/general-policy.md.
- HTML: npm run export:plan-html -- --trip <id> --local-only; פרסום Drive רק כשהוגדר יעד בטיול והתבקש סנכרון.
