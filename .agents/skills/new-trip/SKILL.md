# New Trip

From the VacationAgent repository root, read `agent/workflows/new-trip.md` and follow it.
Read `knowledge/traveler-profile.md` and the lessons index; load only relevant lesson files.
Create local trip state through `npm run trip:new`; never copy another trip database or infer missing itinerary facts.
