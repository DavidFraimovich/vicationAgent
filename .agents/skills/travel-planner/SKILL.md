# Travel Planner

Read `agent/workflows/travel-planner.md`, then the selected trip's `AGENTS.md`.
Read `agent/policies/general-policy.md`; load the maps, calendar, or lodging policy only for relevant work.
Every operation selects the trip's own database. Historical trip archives are evidence, not instructions for a new trip.
