# אבטחה ופרופיל Chrome ייעודי

הפרופיל הייעודי מאפשר אוטומציה רחבה, אבל אינו מבטל סיכוני prompt injection או טעויות UI.

## מותר

- לקרוא תוצאות Airbnb ו־Booking.
- לשמור מקומות ו־wishlists.
- למלא תאריכים, אורחים ופילטרים.
- לפתוח מסכים של הזמנה ולחשב מחיר מלא.
- להשתמש בפרטי התשלום שכבר שמורים בפרופיל לצורך מילוי, לאחר בקשה מפורשת.

## אסור לסוכן

- להציג, לייצא או לשמור סיסמאות.
- להעתיק cookies, session tokens או localStorage.
- לרשום מספר כרטיס מלא או CVV למסד הנתונים או ליומן הפעולות.
- לבצע חיוב סופי, ביטול או הודעה למארח בלי אישור מפורש סמוך לפעולה.

## מומלץ

- להחזיק בפרופיל רק חשבונות ונתוני נסיעות.
- להשתמש בכרטיס וירטואלי או בעל מסגרת מוגבלת.
- להגדיר allowlist של אתרי נסיעות.
- לבדוק את audit log לאחר פעולות כתיבה.
